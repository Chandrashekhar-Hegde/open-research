# Open Research feedback session

Protocol status: proposed; no participant data collected. Version: 2026-09-08.
Full rationale: https://github.com/Chandrashekhar-Hegde/open-research/blob/main/docs/community-needs.md

Use voluntary, consented sessions with non-sensitive practice material. Obtain
any applicable institutional permissions first. Do not paste personal data,
unpublished results, recordings, credentials, or identifying notes into GitHub.
Participants may stop or skip questions. Keep private notes under the agreed
access and retention rules; publish only permitted, redacted findings.

## Observe each workflow

Use usual practice for one task and Open Research for the other. Counterbalance
order. Allow up to 30 minutes total. Record assistance and unfinished tasks;
do not quietly turn assisted work into an unassisted success.

| Question and unit identified? | | |
| Method justified? | | |

| Unsupported claims left uncorrected | | |
| Frustration: 1 low to 5 high | | |

Ask the participant to explain what the design can and cannot establish.
Where feasible, have an uninvolved domain reviewer assess anonymized artifacts
without knowing which workflow was used. Otherwise disclose review limitations.

## Ask, without leading

1. What were you trying to understand or decide?
2. Where did you get stuck? What happened, and what did you expect?
3. Which step or artifact helped? Which would you remove?
4. Did the shared daily checklist make sense across tasks? Give an example.
5. Did the method questions fit your study? What was missing or unnecessary?
6. What did the tool make look more certain than the evidence justified?
7. Would you use any part of this again? Why, or why not?

## Report honestly

Separate observation, participant statement, and evaluator inference. Report
counts with denominators, paired outcomes, medians/range, failures, and order
effects. Do not claim population benefit or statistical effectiveness from a
small usability pilot. No generated respondents or invented testimonials.

Actionable feedback can be submitted voluntarily at:
https://github.com/Chandrashekhar-Hegde/open-research/issues/new?template=feedback.yml
This opens a public GitHub issue form and requires an account. Downloading or
completing this worksheet does not submit anything.
