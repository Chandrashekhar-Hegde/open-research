Manuscript formats that preserve the work

Choose a subject in Guide paths, then a research paper or review paper. These are authoring scaffolds, not completed papers or submission templates for every journal.

In the browser

  1. Enter your actual question and study decisions. Record executed results in Analyze.
  2. Open Write. Select Research paper or Review paper, then Markdown or Quarto.
  3. Read the outline and expand Preview to inspect the question and working records.
  4. Download the manuscript scaffold. The study Markdown/JSON buttons still export the full study record; editable JSON remains the format for returning to the editor.

Paper type and export format are file-export choices, not scientific classification. They reset when opening another study or reloading; choose them before exporting. No paper text, sources or results are generated by a remote service. The browser scaffold includes entered notes under their original labels. The local CLI scaffold uses the study's structured evidence and claims ledgers instead.

From a checkout

python research.py guides --path review-papers
python research.py draft examples/noaa-co2 --kind research --format markdown --output build/paper.md
python research.py draft examples/noaa-co2 --kind research --format quarto --output build/paper.qmd
quarto render build/paper.qmd --to html
quarto render build/paper.qmd --to docx

Core commands require Python 3.11+. Rendering needs a separate Quarto installation. The example produces an incomplete scaffold based on the real NOAA reanalysis; it is not a finished paper. For your own study, substitute its folder after completing basic metadata and evidence checks. draft refuses an existing output file, including a symlink. Use a new name or explicitly manage earlier versions.

Use --kind review for a review outline. If omitted, a study classified as systematic or scoping defaults to review; other studies default to research. --format defaults to Markdown. .qmd is the filename extension for Quarto. Generated Quarto headers disable executable code blocks; inspect and run analysis separately, preserving its outputs before incorporating them into prose.

Formatting decisions

  • Structure: use the selected paper outline; adapt theoretical work to definitions, assumptions, derivation/proof and consequences. Do not force a proof into a participant study.
  • Tables: title and number them, define units, denominators, missing values and uncertainty. Keep source data available in an appropriate machine-readable form.
  • Figures: use legible axes and captions, explain error bars and independent sample counts, preserve original images and disclose processing. Check venue dimensions and resolution rather than assuming one universal requirement.
  • Equations: define each symbol and its domain, keep units consistent, label assumptions and number equations that the text references. Quarto supports LaTeX math.
  • References: inspect the source; keep exact locators in the evidence ledger. Export verified metadata from your reference manager as BibTeX or CSL JSON. Add bibliography: references.bib to the Quarto header only after creating that real file next to the manuscript. Use actual citation keys such as [@source-key]. A ledger inventory is not an automatically formatted bibliography.
  • Journal style: check the chosen venue's current article type, abstract, limits, citation style and figure requirements. Quarto can use a CSL file or Word reference document; supply permitted, verified local files. PDF rendering needs an additional PDF toolchain and is not part of this core verification.
  • Review record: list who checked methods, computations and sources. Preserve unresolved concerns, negative results, conflicts, contributions and access limits.

Quarto Word documentation explains Word rendering and reference documents. ICMJE manuscript preparation and the discipline guides point to relevant reporting expectations.
