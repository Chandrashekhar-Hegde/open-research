01 / QUESTION & PLAN

Plan a study

1. Prepare your tool

python research.py doctor

2. Start with this command

python research.py init studies/my-study --title "My research question"

What you will have

A question, protocol, analysis plan, and empty evidence records.

Then inspect and decide

Edit study.json, protocol.md, and analysis-plan.md. State what is unknown before you analyze.
