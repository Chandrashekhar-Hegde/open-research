# Research Release

Inspect the study's protocol, evidence, claims, results, data terms, and review
record. Build a concrete release package within the user's requested scope.
Preparation does not itself authorize public posting or third-party messages.
Use publication authorization already given when it applies.

Verify claim-to-source locations, reproduction status, protocol deviations,
limitations, negative results, and unresolved contradictions. Distinguish
mechanical checks, source verification, numerical reproduction, and independent
scientific review. Do not invent review, ethics approval, or endorsement.

Include permissible raw/derived data, code/environment, commands, source and
claim ledgers, report, limitations, artifact hashes, contributor credits,
licenses/access conditions, conflicts/funding when applicable, and actual AI
assistance. Record unknown model metadata as unknown. Avoid exposing private
prompts, participant information, secrets, or restricted third-party content.

Check that the manifest covers every input, analysis file, and reported output.
Run available structural and reproduction checks and explain their limits.
Record pending review honestly; an unverified claim may be shared as unverified,
but must not be rewritten as an established finding.

Return a review record and release note with actionable gaps and citation
metadata. Assign no DOI or registration identifier unless actually issued.
When authorized publication occurs, verify its destination and report the
real version, URL, and remaining access or review limitations.
