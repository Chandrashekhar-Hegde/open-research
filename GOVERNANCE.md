# Governance

Chandrashekhar Hegde maintains this personal, public project. Contributions
and evidence-based disagreements are welcome. The maintainer decides scope,
merges, releases, and conduct responses; additional maintainers will be named
here if appointed. No fictional committee or review quorum is assumed.

Changes arrive through pull requests with passing checks. A maintainer can
merge their own maintenance work, but must not describe it as independent
review. Scientific claims requiring domain review should name that review's
status and unresolved limitations. Automated checks establish only their
specified mechanical properties.

Decisions should explain the research need, evidence, and tradeoffs. Correct
errors openly, retain version history, and document material changes to
methods or conclusions. Deprecate unsupported workflows with a replacement
or explanation. No automatic quarterly review is promised.

Authorship reflects actual contributions; AI tools are disclosed as tools.
See [contributors](CONTRIBUTORS.md), [conduct](CODE_OF_CONDUCT.md), and
[contributing](CONTRIBUTING.md).
