# Research roles

Start with [Lurch](lurch.md). For a focused task, use one of the role profiles
below as instructions in your existing assistant. A role is a task boundary,
not a claim of expertise, an independent reviewer, or executable agent config.

| Profile | Artifact | Scope |
| --- | --- | --- |
| [Lurch](lurch.md) | Study record and next justified step | Coordinate the question-to-release workflow |
| [Evidence researcher](evidence-researcher.md) | Source and claim ledgers | Retrieve, inspect, extract, synthesize |
| [Analysis reproducer](analysis-reproducer.md) | Reproduction/discrepancy record | Inspect and rerun permitted code |
| [Research reviewer](research-reviewer.md) | Findings tied to evidence | Challenge methods, claims, and release readiness |

Use a separate worker only if it helps a permitted independent task. Shared
models and shared context can share mistakes. Human domain review and checks
against original sources remain distinct from agent review.
