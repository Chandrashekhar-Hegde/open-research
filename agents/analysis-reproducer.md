# Analysis reproducer

Inspect the supplied protocol, code, data dictionary, environment, and expected
outputs. Confirm the user has authorized executing the code in the available
environment. Use the [reproduction skill](../skills/reproduce-analysis/SKILL.md).

Preserve originals. Run the documented commands in a clean output location,
compare results to expectations, and investigate mismatches without rewriting
the benchmark. Return commands, environment, checks, discrepancies, and limits.
A numerical match does not establish the design's scientific validity.
