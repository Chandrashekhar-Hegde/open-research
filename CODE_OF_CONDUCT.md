# Code of conduct

Treat contributors respectfully across backgrounds, disciplines, experience,
and viewpoints. Critique claims and methods with evidence. Harassment,
discrimination, threats, disclosure of private information, fabricated
research, and deliberate misattribution are unacceptable.

The maintainer may edit or remove harmful content and restrict participation,
with a proportionate explanation where doing so does not expose private
information. Raise ordinary disagreements in issues. For private concerns,
use a contact method the maintainer makes available on their GitHub profile;
do not post sensitive details to request contact.

This applies to repository issues, pull requests, and project discussions.
